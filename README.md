# Amazon-Automation
### 📊 Amazon Sales Analytics Dashboard

* Built an interactive **Amazon Sales Analytics Dashboard** using **Python and Streamlit**.
* Cleaned and processed sales data using **Pandas**.
* Performed **feature engineering** on order date, including Month, Day, Hour, City, and State.
* Created **KPI metrics** such as Total Sales, Total Orders, Average Order Value, Top Product, and Top City.
* Added interactive filters for **City, Product, and Order Date**.
* Created interactive visualizations using **Plotly** for sales trends, products, cities, states, and order patterns.
* Analyzed **best-selling products** and **frequently bought-together products**.
* Added automatic **business insights** based on the filtered data.
* Added a **Data Explorer** with filtered-data download functionality.
* Designed a responsive, professional dashboard UI suitable for **business and portfolio presentation**.

**Tech Stack:** `Python | Pandas | Streamlit | Plotly | Data Cleaning | EDA | Data Visualization`
